# 실험: 8D 초안(D2·D4) 묶음 표본 관찰 — 아직 실제 호출 결과 없음 (2026-10-16)

> 목적: 담은 선례의 원문을 LLM이 **묶고 제목만 붙이게** 했을 때 쓸 만한지, 그리고 서버의 원문 대조(`server/rag/draft.py`)가 글자를 바꾼 인용을 막는지 본다(DEC-065). **평가가 아니다** — 정답이 없고 "쓸 만한가"는 사람이 읽고 판단한다. 서비스 수치로 올리지 않는다.
> **상태: 실제 LLM 호출 14회가 모두 `401 invalid_api_key`로 실패해 묶음 품질·원문 대조 통과율은 재지 못했다.** 아래 3절의 "후퇴 동작"만 실제로 확인했다.

## 1. 조건

- 모델: `gpt-6-luna`, 추론 강도 `none`(사용자 지정 2026-10-16 — DEC-056 ③의 두 번째 예외, 첫 번째는 `docs/실험_LLM단독기준선.md`). 요청은 OpenAI Responses API(`POST /v1/responses`)에 `text.format = json_schema(strict)`, `reasoning.effort`, `store: false`, `max_output_tokens: 1500`.
- 입력: 공개 검색 API(`https://lg-cns-rag.vercel.app`, build `5e32c164b15a544a`, 스냅샷 2026-10-06)에 질문 7개를 넣어 받은 선례. D2는 전체 순위 위쪽 6건의 결함·결과 문장, D4는 **원인 원문이 있는 선례** 중 위쪽 6건의 원인 칸(사용자가 화면에서 "원인 원문 있음"을 골라 담는 상황). 질문은 저장소에 출처가 있는 것만 썼다(화면 예시 4개, 시연 질문, 검색창 안내 문구, 시연 대체 질문) — 새로 지어 쓰지 않았다.
- 호출 코드는 서버와 같다(`server.rag.draft.call_llm`·`generate`) — 서비스 경로 자체를 시험한다. 스크립트: `scripts/defect_precedent/draft_sample.py`.
- 비용 추정(호출 전): 14호출, 입력 약 14,400토큰 + 출력 상한 21,000토큰 → **상한 약 0.012달러**(Luna 입력 0.10·출력 0.50달러/100만 토큰 — `docs/실험_LLM_Luna비교.md` 1절, 출력은 상한 기준이라 실제는 훨씬 적다). 사용자 승인: 모델 `gpt-6-luna`·D2·D4만(2026-10-16 대화).

## 2. 보려던 것 (결과 없음)

- 구조적 사실: LLM 인용 중 원문에 없던 것의 수(`rejected.not_in_source`), 묶음 수, 제목이 판정 표현에 걸린 수(`bad_title`), 묶이지 않은 원문 수, 토큰·시간·비용.
- 사람이 읽고 볼 것: 묶음 제목이 원문이 말하는 것만 설명하는가, 서로 다른 표현(예: "PCB controller"·"Printed Circuit Board")을 같은 묶음으로 잘 묶는가, "N/A"·"NR" 같은 원인 미보고 서술을 따로 묶는가.

## 3. 실제로 일어난 일

| 항목 | 결과 |
|---|---|
| 호출 | 14회(질문 7 × D2·D4) — **전부 실패**: OpenAI가 `HTTP 401`, `type: invalid_request_error`, `code: invalid_api_key` |
| 키 점검(값은 보지 않음) | 서버 환경변수에 설정돼 있고 `sk-proj-` 형식, 길이 164, 앞뒤 공백·따옴표 없음 — 형식 문제는 아니고 폐기·교체됐거나 다른 프로젝트의 키일 가능성(추정) |
| 후퇴(`degraded`) | 14건 모두 `llm_failed`(사유 `http`)로 처리되어 **묶음 없이 원문 목록만** 돌아왔다 — 설계대로다. 키·HTTP 본문은 결과에 남지 않았다 |
| 토큰·비용 | 0·0달러(요청이 거절돼 과금되지 않았다고 본다 — 확인하지 않음) |
| 확인하지 못한 것 | 요청 형식(`reasoning.effort`, `json_schema strict`, `store`)이 실제 API에서 받아들여지는지(401은 형식 검사 전에 걸린다), 응답 해석(`output[].content[].output_text`)이 실제 응답과 맞는지, 묶음 품질, 원문 대조 통과율. 요청·응답 형식은 OpenAI API 레퍼런스(외부, developers.openai.com/api/reference, 2026-10-16 확인)로만 확인했다 |

## 4. 다시 돌리려면

```bash
# 키를 바꾼 뒤 (값은 출력하지 않는다)
uv run --env-file .env python -m scripts.defect_precedent.draft_sample --out <결과.jsonl>
# 호출 없이 입력·호출 수·비용 상한만
uv run python -m scripts.defect_precedent.draft_sample --dry-run
```

결과를 본 뒤 정할 것: 제목 프롬프트 손질 여부, `bad_title`·`not_in_source` 비율이 높으면 공개 배포에서 켜지 않는다(DEC-065 ⑥).
