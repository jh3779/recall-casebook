# UI 문구

한국어, 짧게, 사용자가 아는 말로. 결론·판정을 말하지 않는다. 원문 칸은 영어 원문 그대로.

## 상단 바 · 입력

| 위치 | 문구 |
|---|---|
| 브랜드 | 결함 선례 찾기 / NHTSA 공개 리콜 · Part 573 원문 |
| 탭 | 선례 검색 · 3D 쇼룸(데모) |
| 판본 | 카드 {cards}장 · 스냅샷 {snapshot_date} / 서버 확인 중… / 서버 판본을 받지 못했습니다 |
| 입력 자리 표시 | 결함 서술을 영어로 — 예: brake fluid leaking from front caliper |
| 버튼 | 선례 찾기 / 찾는 중… |
| 도움말 | 영어 질문만 받습니다 · 고객사(현대·기아) 최대 5건 + 다른 회사 상위 10건 · {n} / 4000자 |
| 입력 안내 | 영어 단어가 없습니다 |

## 첫 화면

| 위치 | 문구 |
|---|---|
| 예시 | 예시 질문 |
| 하는 일 | 영어 결함 한 줄로 관련 리콜 후보를 찾습니다 — 같은 부품인지는 부품 칩과 확인 항목을 보고 직접 비교합니다 / 결함·결과·시정과 Part 573 원인 칸을 원문 그대로 보여 줍니다 / 원문마다 말한 주체와 출처(리콜 번호·573 파일·조사 번호)를 붙입니다 |
| 하지 않는 일 | 리콜 여부나 원인을 판정하지 않습니다 / 원문을 번역하거나 요약하지 않습니다 / 원문에 없는 원인·공급사를 짐작해 채우지 않습니다 |
| 판본 | 데이터 판본 |
| 쇼룸 | 3D 쇼룸(데모) — Silverado·Ram 차종을 부품 분류로 둘러보는 데모 화면입니다. 데모 스냅샷이라 검색 결과와 다릅니다. [쇼룸 열기] |
