# NHTSA 결함 조사 블록

카드에 연결된 조사(`investigations[]`)가 있을 때만 보인다(현재 build에서 카드 1,870장, 조사 917건 — `server/README.md`).

## 구성

제목 "NHTSA 결함 조사" + 회색 알약 "{n}건 연결". 조사마다:

| 줄 | 내용 |
|---|---|
| 1 | 조사 번호 `action`(`--font-id` 굵게) · `subject` 굵게 · "개시 {open_date} / 종결 {close_date}" |
| 2 | 바이라인 `말한 주체 **NHTSA 결함 조사 (조사관 요약)**` |
| 3 | `details` "＋ 조사 요약 원문" → 펼치면 `summary` 원문(`--font-source`, `pre-wrap`, `lang="en"`) |

조사가 여럿이면 점선(`--line`)으로 나눈다.

## 규칙

- 날짜는 원본 칸 그대로(`YYYYMMDD` → `YYYY.MM.DD`). `close_date`가 비면 "기록 없음" — "진행 중"이라고 짐작하지 않는다.
- 조사 요약은 길어서 기본으로 접는다. 원문은 앞뒤 공백까지 서버 값 그대로.
- 꼬리표를 붙이지 않는다(서버에도 없음 — DEC-044).
- 조사 요약은 시험 질문의 출처이기도 하다 — 화면은 검색 뒤 카드에 "왜"를 붙이는 데만 쓴다(검색 색인에는 넣지 않음, 기획 5절 주의 2).
