# 상단 바 · 화면 전환

검색 화면과 3D 쇼룸이 함께 쓰는 맨 위 줄.

## 구성 (왼쪽 → 오른쪽)

| 요소 | 내용 | 토큰 |
|---|---|---|
| 브랜드 | 남색 원뿔 그라데이션 마크(22px, 모서리 7px) + "결함 선례 찾기" / 아래 작게 "NHTSA 공개 리콜 · Part 573 원문" | `--accent`, `--fs-xs`, `--ink-2` |
| 화면 탭 | `[선례 검색 | 3D 쇼룸(데모)]` — 알약 모양 묶음, 선택된 탭은 남색 바탕 흰 글자. "(데모)"는 `--ink-3` | `--surface-2`, `--accent`, `--on-accent`, `--radius-pill` |
| 빈 칸 | 남는 폭 | |
| 서버 판본 | 점 + "카드 30,350장 · 스냅샷 2026-10-06" | `--fs-xs`, `--ink-2` |

배경은 `--glass` + `backdrop-filter: blur(10px)`, 아래 구분선 `--line`.

## 동작

- 탭 상태는 주소 해시로 기억: `#search`(기본) / `#showroom`. 새로 고침해도 같은 화면.
- 쇼룸은 따로 불러온다(three.js를 검색 화면이 받지 않게). 3D 모델을 못 불러와도 상단 바와 검색 탭은 그대로 동작한다.
- 판본 점: 화면에 들어오면 `GET /health`를 한 번 부른다(서버 깨우기 겸).

| 상태 | 점 | 글 |
|---|---|---|
| 받는 중 | 빈 점(`--ink-3` 테두리) | "서버 확인 중…" |
| 받음 | 채운 점(`--accent-2`) | "카드 {cards}장 · 스냅샷 {snapshot_date}" — 마우스를 올리면 build_id·묶음 sha256 전체(보조). 전체 값을 터치·키보드로 보는 길은 상세 출처 꼬리의 "판본 자세히"([precedent-detail.md](precedent-detail.md#출처-꼬리)) |
| 실패 | 빈 점 | "서버 판본을 받지 못했습니다" (검색은 막지 않음) |

## 접근성

탭은 `button` 두 개(`aria-pressed`), 키보드로 이동·선택 가능, 초점은 `--focus`.
