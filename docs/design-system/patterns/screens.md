## 2. 결과 (데스크톱 1280px 이상)

```
상단 바 / 검색 입력(질문 그대로 남음)
┌ 목록 300~380px ───────┬ 상세 ─────────────────────────────┐
│ 고객사 선례 · 현대·기아 │ 전체 순위 6 · 14E073000 · Takata … │
│  #15 26V307000 …       │ [AIR BAGS]                          │
│  #66 11V179000 …       │ ┌ 결함·결과·시정 (NHTSA 원문) ┐    │

│  #1 13E017000 …        │ ├ NHTSA 결함 조사 1건 연결    ┤    │
│  …                     │ ├ 확인 항목                    ┤    │
│  #6 14E073000 ◀선택    │ └ 출처 꼬리 build·묶음·스냅샷 ┘    │

```

목록과 상세는 각자 스크롤한다. 결과가 오면 첫 항목을 선택한 상태로 연다.

## 3. 모바일 (390px)

1. 결과 목록 화면: 상단 바(탭은 줄여서) → 검색 입력 → 목록(한 단).
2. 항목을 누르면 상세 화면: 맨 위 "← 목록" → 상세(블록은 한 열, 확인 항목·출처 표도 한 열).

## 4. 로딩 · 오류

[feedback.md](../components/feedback.md). 오류 화면은 입력 칸 아래 오류 상자 하나, 입력한 질문은 그대로.

## 5. 쇼룸 연결

- 상단 탭으로 오간다(`#search` ↔ `#showroom`). 쇼룸은 데모 스냅샷이라 "데모" 표시를 붙인다.
- 쇼룸 3D 모델을 못 불러와도 실패 안내에 "검색 화면으로" 버튼을 둔다.
- 쇼룸에서 부품 분류 → 검색으로 이어 주기는 [열린 질문 1](../open-questions.md).
