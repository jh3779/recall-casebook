# 간격 · 모서리 · 그림자 · 반응형

## 간격

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--sp-1` | 4px | 칩 사이, 탭 안쪽 |
| `--sp-2` | 8px | 배지·칩 묶음, 목록 항목 사이(6px도 허용) |
| `--sp-3` | 12px | 블록 안 항목 사이, 목록 패널 안쪽 |
| `--sp-4` | 16px | 블록 안쪽, 화면 좌우 최소 여백 |
| `--sp-5` | 24px | 상세 패널 안쪽, 블록 사이(18px도 허용) |
| `--sp-6` | 32px | 화면 구역 사이 |
| `--sp-7` | 48px | 문서·큰 구역 사이 |

형제 요소 사이 간격은 `gap`으로만 준다(요소마다 margin을 주지 않는다).

## 모서리

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--radius` | 18px | 쇼룸 패널(쇼룸과 같음) |
| `--radius-s` | 10px | 블록·목록 항목·입력·버튼·오류 상자 |
| `--radius-pill` | 999px | 배지·탭·예시 질문 |
| (칩) | 6px | 부품 칩 |

## 그림자 · 초점

| 토큰 | 값 | 규칙 |
|---|---|---|
| `--shadow-panel` | `0 1px 2px rgba(21,24,29,.06), 0 8px 24px rgba(21,24,29,.06)` | 앱 틀(바깥) 하나에만. 블록은 선만 쓰고 그림자를 주지 않는다 |
| `--focus` | `0 0 0 3px rgba(44,90,160,.35)` | 입력칸 `:focus-within` 보조 테두리만 |
| 키보드 초점 | `:focus-visible { outline: 2px solid var(--accent-2); outline-offset: 3px }` | 모든 버튼·입력·목록 항목·`summary`에. **불투명 `outline`**(`--accent-2` 흰 바탕 대비 6.82:1)이라 선택 항목의 안쪽 띠(`box-shadow: inset`)와 다른 속성이어서 겹쳐 사라지지 않는다. `box-shadow`로 초점을 그리지 않는다 |

움직임은 짧게(0.15~0.2초), `prefers-reduced-motion: reduce`이면 끈다. 로딩 뼈대의 반짝임도 끈다.

## 반응형

| 폭 | 배치 |
|---|---|
| 1280px 이상(노트북·발표 화면 우선) | 목록 300~380px + 상세 나머지, 2단 |
| 768~1279px | 같은 2단, 목록 300px 고정 |
| 767px 이하(모바일, 기준 390px) | 한 단 — 목록 화면 → 항목을 누르면 상세 화면, 상세 위 "← 목록" |

화면 좌우 여백은 최소 16px. 본문이 가로로 스크롤되지 않게 글이 든 그리드·플렉스 자식은 `min-width: 0`. 긴 번호·sha256은 줄을 바꾸거나 앞 12자 + `…`로 줄인다. 줄인 값의 전체는 터치·키보드로 여는 영역(묶음 sha256은 출처 꼬리의 "판본 자세히" — [precedent-detail.md](../components/precedent-detail.md#출처-꼬리))에 두고, `title`은 마우스 사용자를 위한 보조로만 쓴다.
