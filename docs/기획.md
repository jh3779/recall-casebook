## 1. 문제 정의 (상황별로 디테일하게)

> **대상 · 결핍 · 구체적 어려움** 세 요소가 다 있어야 한다.
> "불편하다"로 끝나면 안 된다. 듣는 사람이 그 사람을 머릿속에 그릴 수 있어야 한다.

### 배경: 규제 3단계

```text
[의회]   Clean Air Act (청정대기법)                          ← 법 제정
  ↓
[EPA]    40 CFR Part 63 (유해대기오염물질 배출 규정, NESHAP)   ← 업종·배출물질별 세부 규칙
  ↓
[공장]   Title V Permit (통합 대기 배출 허가) 취득             ← 취득해야 공장 운영 가능
```

Title V 허가 뒤 5년 동안 공장은 준수 서류를 주기적으로 작성해야 한다. 서비스의 진입 지점은 여기다.

| 서류 | 주기 | 근거 |
|---|---|---|
| 반기 모니터링 보고 | 6개월 | 40 CFR 70.6(a)(3)(iii)(A) |
| 연간 준수 인증 (책임자 서명) | 1년 | 40 CFR 70.6(c)(5)(i), 70.5(d) |
| 초과 배출 신고 | 발생 시 (연방 프로그램 24시간 이내) | 40 CFR 70.6(a)(3)(iii)(B), 71.6(a)(3)(iii)(B) |
| 허가 갱신 신청 | 5년 (만료 6~18개월 전) | 40 CFR 70.6(a)(2), 70.5(a)(1)(iii) |

| 항목 | 내용 |
|---|---|
| 1차 대상 (구체적으로) | Title V 허가를 받은 **미국 중소 제조 공장의 환경·규제 담당자**. 사내 법무팀이 없고, 현장 말("도장 라인, 용제 연 12톤")은 알지만 법률 용어는 약하다. 연간 인증서에 자기 이름으로 서명한다. |
| 그 사람이 처한 상황 | 위 4종 서류를 쓸 때마다 "이번 서류에서 우리 공장에 적용되는 조항은 무엇이고, 무엇을 확인해야 하지?"를 매번 다시 마주한다. 텍사스 TCEQ 가이드는 위반 보고서·인증서에 **조항 번호를 직접 적도록** 요구한다. |
| 없어서 못 하는 것 | 현장 말로 물으면 **근거 조문과 확인할 기준을 바로 찾아 주는 도구**가 없다. Part 63은 PDF 957쪽 · Subpart 158개 · 조문 2,473개 · 표 784개(약 463만 토큰)이고, 2018~2025년 개정 136건(월 1회 이상), 현재 조문의 45%가 바뀌었다. |
| 그래서 무엇이 어렵나 | **찾기**: 957쪽에서 우리 설비에 해당하는 조문 찾기. **판단하기**: 적용 여부를 가르는 기준 파악하기. 틀리면 서명자 개인이 법적 책임(70.5(d))을 지고, 갱신이 늦으면 가동 권리가 끝난다(70.7(c)(1)(ii)). 대상 시설 49,618곳 중 27.9%에 위반 이력, 2015년 이후 처분 9,998건($958.8M). |
| 현재는 어떻게 때우고 있나 | ① **EPA에 공식 판정 요청** — 회신 중앙값 101일, 28%는 6개월 이상(CAA Dashboard 판정서한 199건 실측). 공개된 Part 63 문의만 1,127건(ADI 995 + CAA Dashboard 132). ② **변호사·컨설턴트** — 비용이 크고 즉답이 어렵다. ③ 허가서·eCFR·기억에 의존 (콜드메일 질문 1번으로 확인 중, 응답 결과는 full에 없음). |

**문제 정의 한 문장**:
> 미국 중소 제조 공장의 환경 담당자가 / 반기 보고·연간 인증·초과 신고·갱신 서류를 쓸 때 / 현장 말로 물어 최신 근거 조문을 바로 찾아 줄 도구가 없어서 / 자기 이름으로 서명할 조항 번호를 정확히 찾고 확인하기 어렵다.

### 해결 범위 — 어디까지 풀고 어디부터 안 푸나

> ❗ 자주 빠뜨리는 칸. "못 한 것"과 "안 하기로 한 것"을 구분해서 적어야 신뢰를 얻는다.

| 단계 | 해결 여부 | 비고 |
|---|---|---|
| 현장 말 질문 → 후보 조문 찾기 | ✅ 해결 | 정답 조문 Hit@5 0.931, Hit@20 0.961 (평가셋 102건) |
| 적용을 가르는 기준 + 확인 체크리스트 제시 | ✅ 해결 | 모든 문장에 `40 CFR 63.xxxx(a)` 근거, 인용 근거율 99.6% |
| 규정 개정 자동 반영 | 🟡 부분 | 원문 수집·적재는 매일 자동. **검색 색인 재생성은 사람이 실행** (서명할 조항이 바뀌는 순간이라 일부러 남김) |
| Subpart A(공통 조문) 검색 | 🟡 부분 | 정답에 Subpart A가 있는 29건 중 20건이 상위 10에 못 올라옴 — 검색 쪽 과제로 남김 |
| "적용됩니다/안 됩니다" 판정 | ❌ 미해결(의도적) | 판정은 법률 자문. 답변 JSON에서 `applies`·`verdict` 필드를 아예 없앰 |
| Part 63 이외 규정 (Part 60, 주 규정 등) | ❌ 미해결(의도적) | 데이터 범위를 Part 63으로 한정 |
| 대기업 | ❌ 대상 외 | 사내 법무팀·로펌이 있어 빈틈이 작음 |

**실패하는 경우**:
- 정답 조문이 검색 상위 10개에 안 들어오면 답변이 그 조문을 인용할 수 없다 — 놓친 정답 71개 중 53개가 이 경우(full "상위 10개 조문" Q&A).
- 답변 1건에 약 20초(LLM 리랭크)가 걸려 채팅형 즉답에는 맞지 않는다 — 며칠에 걸쳐 쓰는 서류 작성용으로 설계했다.
- 주(州)마다 다른 신고 기한 등 Part 63 밖의 규정은 답하지 못한다.

## 3. 이 기술이 왜 들어가야 하는가

> 기술이 목적이 되면 안 된다. **"그 기술 없이는 안 됐던 것"**을 먼저 쓴다.

| | 그 기술 없이 | 그 기술로 |
|---|---|---|
| **RAG** | Part 63 약 463만 토큰은 LLM 컨텍스트에 안 들어간다 (Anthropic 문서도 20만 토큰 이상이면 RAG 권장) | 질문에 맞는 조문 10개만 골라 넘긴다 |
| **RAG + 자동 재적재 파이프라인** | LLM은 학습 시점 이후 개정을 모른다 (개정 136건, 조문 45% 변경) | 매일 원문을 다시 받고, 개정 공고 1,916건을 고친 조항 3,005건·시행일 792건에 연결 |
| **근거 인용 강제 + 인용 근거율 측정** | LLM이 그럴듯한 조문 번호를 지어낸다 — 서명자에게 치명적 | 답의 인용이 넘겨준 조문 안에 있는지 측정 (인용 근거율 0.996~1.000) |
| **Contextual Retrieval** | `(b) The owner or operator shall...`만 떼면 어느 업종·설비 얘기인지 모른다 | 청크마다 LLM이 2~3문장 맥락을 붙여 [설명 + 원문]을 임베딩 |
| **리랭커 + LLM 리랭크** | 정답을 20개 안에선 84% 찾지만 5개 안에선 69% (순서가 밀림) | Hit@5 0.686 → 0.931 |

**정직하게 남길 지점**:
- 인용 Recall 0.785 상한은 **검색**에 묶여 있다 — 답변 프롬프트로 올릴 수 있는 상한은 0.78.
- LLM 리랭크로 질문당 약 20초가 늘었다.
- 판정은 기술로 풀지 않기로 했다 (원칙 문제).

## 5. 아키텍처 · 워크플로우 설계

```text
[데이터]  eCFR(규정 원문) · Federal Register(개정 공고) · EPA ECHO(점검·위반·벌금) · ADI/CAA Dashboard(EPA 판정서한)
             │  매일/매주 자동: 받기 → 읽기 → 넣기 → 검사 → 공개 (버전 단위, 원본 4,915개 보관)
             ▼
[DB]      PostgreSQL(Supabase) — 테이블 43개, ODCS 계약서로 고정
             │  색인 재생성은 Slack 알림 확인 후 사람이 실행
             ▼
[색인]    조문 1개 = 청크 1개 (30,000자 초과 시 (a)(b) 경계 분할, 5,625개) + Contextual Retrieval
             ▼
[검색]    Kanon 2 벡터 상위 150 ─┐
          BM25 키워드 상위 150 ──┴─► RRF 병합 → Kanon 2 Reranker → 후처리 규칙 → LLM 리랭크(상위 20)
             ▼
[답변]    상위 10개 조문 전문 → gpt-5-mini → JSON (후보 조항 · 적용 기준 · 확인 체크리스트 · 조문 근거)
             ▼
[화면]    FastAPI(Render) ← Next.js(Vercel)
```

**핵심 흐름**: 공장 담당자의 질문(현장 말) → 하이브리드 검색 → 리랭크 → 상위 10 조문 → 근거 달린 후보 조항·체크리스트(JSON)

**설계 제약** (어겨서는 안 되는 것):
1. **판정하지 않는다** — 답변 JSON에 `applies`·`verdict` 필드를 두지 않는다. 약속을 문구가 아니라 구조로 지킨다.
2. **근거 없는 말은 하지 않는다** — 모든 기준 문장에 `40 CFR 63.xxxx(a)` 조문을 단다.
3. **추적 가능해야 한다** — 답변 → 근거 조항 → 데이터 버전 → 원본 파일 → 원본 위치(XML 줄 번호)까지 되짚을 수 있어야 한다.
4. **반쯤 들어간 적재는 없다** — 적재는 전부 또는 전무.
5. **품질 합격선 아래면 병합 금지** — 검색: nDCG@10 ≥ 0.66, Hit@20 ≥ 0.95, Subpart@20 ≥ 0.95 / 답변: Subpart ≥ 0.93, 인용 Recall ≥ 0.70, 인용 근거율 ≥ 0.96, 판정 기준 점수 ≥ 1.71.

## 6. 개선 사항 — 지금까지 / 앞으로

> ❗ **before → after를 수치로.** 이 표가 "점진적 발전"에 대한 답이다.
> 성능만 있고 품질이 비면 반쪽이다. 둘 다 채운다.

평가셋: 실제 공장이 EPA에 물은 질문을 판정서한에서 추출한 **102건**(PoC 32건 → 확장). 정답은 EPA가 그 서한에서 인용한 조문. 0.03 미만 차이는 "같다"로 본다.

### 지금까지 한 개선 — 검색 (주 지표 nDCG@10)

| 항목 | before | after | 무엇을 바꿔서 |
|---|---|---|---|
| 임베더 | 0.297 (bge-m3) | 0.437 | 법률 특화 Kanon 2 + Contextual Retrieval |
| 리랭커 | 0.437 | 0.561 | Kanon 2 Reranker — Hit@5 0.686 → 0.804 |
| 하이브리드 | 0.561 | 0.568 | BM25 + RRF — Recall@20 +0.03 때문에 유지 |
| 후처리 규칙 | 0.568 | 0.631 | 부록 표는 뒤로, 이미 찾은 Subpart·Subpart A 우선 |
| LLM 리랭크 | 0.631 | **0.692** | gpt-5-mini로 상위 20 재정렬 — Hit@5 0.882 → 0.931 (대가: 질문당 약 20초) |

### 지금까지 한 개선 — 답변 품질

| 항목 | before | after | 무엇을 바꿔서 |

## 7. 어려움과 해결

> ❗ 사례를 나열하지 말고 **하나의 서사로 엮는다**. "우리는 이런 식으로 일한다"가 드러나야 한다.
> 작업 중에 그때그때 적어 두지 않으면 나중에 절대 못 쓴다.

| 언제 | 막힌 지점 | 어떻게 접근했나 | 결과 | 남은 것 |
|---|---|---|---|---|
| Contextual Retrieval 시범 색인 (11청크) | 모델이 Subpart XXXXXX를 전부 "Subpart RRR"로 바꿔 부름 | "지어내지 마라" 프롬프트는 효과 없음 → 원인은 조문 본문에 자기 Subpart 이름이 없음("this subpart"만) → Subpart 제목을 프롬프트에 직접 주입 | 955개 재색인에서 재발(호출부가 조문 제목을 넘김) → 전체 삭제·수정 후 5,625개 재색인 | 전체 색인 전 **사람이 표본을 먼저 읽는 단계** 유지 |
| 데이터 수집·파싱·적재 | 정부 데이터가 설명서와 다르게 들어옴 (17곳) | 단계마다 예측과 실제를 대조 — 수집 중 원본 변경, 표 칸 경계 소실, 벌금 중복 합산(2,511줄) 등 | 17개 수정, 원본 대비 줄 수·날짜 검사 통과분만 공개 | 연결 못 한 코드 35,831줄은 추측 없이 빈칸 |
| 첫 자동 갱신 실행 | 규정 원문 검사가 "글 2건이 사라졌다"며 공개 차단 | 원인: 9/25 개정본 수식의 절댓값 기호 → 비교 방식 수정 후 실제 원문으로 재확인 | 틀린 데이터가 나가는 대신 멈추고 알림 | — |
| Subpart A 고정 포함 실험 | 인용 Recall +0.046인데 채택할지 | 실패 케이스를 직접 열어 봄 → 정답을 미리 아는 꼼수 + 비용 +60% + Judge 하락 | **기각**, run·점수는 기록 보존 | 검색 쪽 과제로 이관 (6번 v2) |

**꿰는 한 문장**: 데이터도, 모델도, 점수도 그대로 믿지 않고 — 직접 열어 보고, 숫자로 확인하고, 이상하면 멈춘다.
