## 6. 작업 방식 (개발 기간)

- 브랜치·커밋·PR 규칙은 [`CONTRIBUTING.md`](../CONTRIBUTING.md), 셋팅은 [`시작하기.md`](시작하기.md)를 따른다.
- 파트 하나 = 이슈 하나 = PR 하나. PR은 하루 안에 끝낼 크기로 나눈다.
- 파트 사이 입출력(함수 이름, 데이터 모양)은 10/10까지 이슈에 적어 두고, 바꿀 때는 해당 파트 담당에게 먼저 알린다.

| | 지금 절차 | 개발 기간 간소화안 |
