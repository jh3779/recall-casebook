# 회사명 대응표 확인 안내

> 대상: 이승노 님(D 파트). 코드를 몰라도 엑셀·구글 시트로 할 수 있는 확인 작업입니다.
> 만든 곳: PR #29 · 결정 기록: DEC-033 · 이슈 #24 A파트 "회사명 대응표를 `maker` 칸에 반영"

## 1. 왜 필요한가

리콜 신고서에는 같은 회사가 여러 이름으로 적혀 있습니다. 예를 들면 `FORD MOTOR COMPANY`와 `Ford Motor Company`, `GENERAL MOTORS CORP.`와 `General Motors LLC`입니다. 이대로 두면 사용자가 "GM의 선례"를 찾을 때 일부만 보입니다. 그래서 이름을 정리한 표를 만들었고, 사람이 맞는지 확인해야 합니다.

## 2. 파일과 칸

파일: `scripts/defect_precedent/maker_aliases.csv` (엑셀에서 열면 됩니다. 한글이 깨지면 "UTF-8"로 열기)

| 칸 | 뜻 |
|---|---|
| `raw_maker` | 신고서에 적힌 이름 그대로 (고치지 않습니다) |
| `maker` | 정리한 이름. 대소문자·쉼표·Inc/Incorporated 같은 표기 차이와 **법인 형태 차이(Corp ↔ LLC)를 한 이름으로 통일**했습니다 |
| `maker_group` | **"같은 회사의 선례"로 묶어 볼 단위.** 미국 법인과 본사(Hyundai Motor America ↔ Hyundai Motor Company), 이름이 바뀐 회사(Chrysler → FCA → Stellantis)를 한 묶음으로 봅니다. 모든 줄에 값이 있고, 묶을 곳이 없으면 `maker`와 같습니다 |
| `count` | 그 이름으로 신고된 리콜 건수. 파일은 많은 순서로 정렬돼 있습니다 |
| `maker_basis` | `maker`를 어떻게 정했나: 원문(그대로) · 표기 통일 · 법인 형태 통일 |
| `group_basis` | `maker_group`을 어떻게 정했나: **없음**(묶을 이름 없음) · **자동**(이름의 핵심 단어가 같음) · **초안**(제가 아는 지식으로 이름을 지정한 것 — 확인 전) |
| `review` | `확인 필요`로 표시된 줄이 먼저 볼 대상입니다 (현재 25줄) |

## 3. 이미 정해진 규칙 (팀 결정)

1. **법인 형태만 다르면 한 회사**로 봅니다. (`GENERAL MOTORS CORP.` = `General Motors LLC`)
2. **미국 법인과 본사는 `maker`는 따로, `maker_group`은 같게** 둡니다. (`Hyundai Motor America`와 `Hyundai Motor Company`는 다른 `maker`, 같은 `maker_group`)
3. **이름이 바뀐 회사도 `maker`는 신고 당시 이름을 유지하고, `maker_group`으로만 잇습니다.** (Chrysler 계열은 `maker`가 5가지 이름으로 남고 `maker_group`이 하나)

## 4. 해 주실 일

### ① `review = 확인 필요` 25줄 (우선)
`maker_group`이 맞는지 봅니다. 틀렸으면 `maker_group` 칸을 고치고, 맞으면 그대로 두면 됩니다.
- **초안(21줄)**: Chrysler 계열, Kia, Toyota, Volkswagen. 같은 회사로 이어도 되는지 판단해 주세요.
  - 예: `DAIMLERCHRYSLER CORPORATION`과 `CHRYSLER LLC`를 Chrysler와 같은 묶음으로 봐도 되는가
  - 예: `Toyota Motor Engineering & Manufacturing`(미국 생산 법인)을 Toyota로 묶어도 되는가
- **자동(4줄)**: `Palfinger`, `Renault`처럼 핵심 단어가 하나뿐이라 우연히 같은 이름일 수 있는 경우.

### ② 큰 회사에서 빠진 연결 찾기
`count`가 큰 위쪽 **100줄 정도**만 훑어보세요. 1건짜리 회사 약 2,000곳은 확인해도 효과가 거의 없습니다. 같은 계열인데 `maker_group`이 다른 이름으로 남아 있으면 `maker_group`을 같은 값으로 맞춰 주세요.
- 이 표는 이름이 비슷한 것만 자동으로 묶습니다. 이름이 전혀 다른 계열사나 합병·인수 관계(예: 브랜드와 모회사)는 **자동으로 알 수 없어서 사람이 채워야 합니다.**

### ③ 확신이 없으면
지우거나 추측해서 채우지 말고 해당 줄 `review` 칸에 `?`를 적고 메모를 남겨 주세요. 확신 없는 묶음을 넣는 것보다 묶지 않는 쪽이 안전합니다. (사용자가 서류에 쓰는 정보입니다)

## 5. 돌려주는 방법

- 수정한 `maker_aliases.csv`를 그대로 박예원 님께 전달하거나, 바꾼 줄만 따로 메모해 주세요.
- 받으면 박예원 님이 다음을 진행합니다: 카드(`recalls.jsonl`)의 `maker`·`maker_group`에 반영 → 새 기준 파일 만들기 → 점수가 그대로인지 확인(재현). 이 작업이 끝나기 전까지는 기존 기준 점수 0.510에 영향이 없습니다.

## 6. 주의

- 이름 목록은 NHTSA 공개 리콜 파일의 `MFGNAME`입니다. 기업 정보를 외부에서 가져온 것이 아니라 **이 파일에 적힌 이름만** 다룹니다.
- `초안` 값은 확인 전입니다. 확정 전에는 화면·답변에 "같은 회사"라고 단정해서 쓰지 않습니다.
