## 용어 풀이

- **RAG**: AI가 관련 문서를 먼저 찾아보고 그걸 근거로 답하는 방식.
- **브랜치**: 원본(main)을 건드리지 않고 따로 작업하는 공간.
- **PR**: "내 작업을 원본에 합쳐 주세요" 요청서.
- **병합**: PR 내용을 원본에 합치는 것.
- **이슈**: 할 일을 적어 두는 게시글.
- **CI**: 코드를 올리면 자동으로 도는 검사.
- **평가 정답표**: 질문별 정답을 사람이 미리 적은 표. 채점에 쓴다.
- **기준선**: 처음 잰 점수. 나아졌는지 비교하는 출발점.
- **결정 기록(DEC)**: 팀이 정한 것을 번호 붙여 적는 문서.
