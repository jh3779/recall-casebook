**이미 정한 것**

- 회사 지식은 AI를 다시 학습시키지 않고 RAG(문서를 찾아 근거로 답하는 방식)로 다룬다. (결정 기록에는 아직 안 적음)
- n8n은 안 쓴다. 라이선스상 내부·비상업용으로만 쓸 수 있다. (결정 기록에는 아직 안 적음)
- 도구: Python 3.12 + uv, lefthook. 작업 순서: 브랜치(따로 작업하는 공간) → PR → 병합.

- 자동 리뷰는 디스코드 봇이 올린다. (정식 기록 예정)

## 일하는 방법

- 부분 하나 = 이슈 하나 = PR 하나. PR은 하루 안에 끝낼 크기로.
- 부분끼리 주고받는 것(함수 이름, 데이터 모양)은 10/10까지 이슈에 적는다. 바꾸면 담당에게 먼저 알린다.
- 규칙은 [`CONTRIBUTING.md`](../../CONTRIBUTING.md), 설치는 [`시작하기.md`](../시작하기.md).

## 용어 풀이

- **RAG**: AI가 관련 문서를 먼저 찾아보고 그걸 근거로 답하는 방식.
- **브랜치**: 원본(main)을 건드리지 않고 따로 작업하는 공간.
- **PR**: "내 작업을 원본에 합쳐 주세요" 요청서.
- **병합**: PR 내용을 원본에 합치는 것.
- **이슈**: 할 일을 적어 두는 게시글.
- **CI**: 코드를 올리면 자동으로 도는 검사.
- **평가 정답표**: 질문별 정답을 사람이 미리 적은 표. 채점에 쓴다.
- **기준선**: 처음 잰 점수. 나아졌는지 비교하는 출발점.
- **결정 기록(DEC)**: 팀이 정한 것을 번호 붙여 적는 문서.
