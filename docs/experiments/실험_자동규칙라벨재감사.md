# 실험 자동 규칙 라벨 재감사 — 규칙으로 붙인 평가 라벨을 무효 처리한 실패 기록 (평가 아님)

> 닫은 PR #133(작성자 GitHub `powercodingman`, 2026-10-15 작성, 병합 없이 2026-10-21 닫음)에서 **실패 기록만** 옮겨 적은 문서다. 이 저장소에서 다시 잰 것이 없고, 성능 점수도 없다. 아래 수치는 모두 PR #133의 문서·인계 기록에서 읽은 값이며 이 문서가 새로 만든 값은 5절에 "이 문서에서 계산"이라고 표시한 구간뿐이다.

## 1. 한 줄 결론

**질문별 정규식·어휘 규칙으로 붙인 평가 라벨은, 30행씩 다시 읽어 보니 13.3%~33.3%가 바뀌어 세 시트를 모두 무효로 폐기했다.** 폐기한 라벨은 어떤 점수나 유의성 검정에도 쓰지 않았고, 유효한 전수 라벨이 없으면 성능을 보고하지 않기로 했다.

## 3. 무슨 일이 있었나 (PR #133 15절 279~285줄)

- 대상: 100문항 후보 풀(질문 91개, 충실도·원인 표현 검사를 통과한 질문)의 관련도 라벨.
- 첫 시도는 "많은 행을 빠르게 처리하려고 질문별 정규식·어휘 규칙으로 1차 분류하고 일부만 사람이 다시 읽었다." PR 문서는 이 방식이 평가표(부록 B)의 "두 글을 읽고 판단"을 충족하지 않는다고 적었다.
- 재감사: 범위를 고정 해시로 정한 30행씩을 다시 표시해 첫 라벨과 비교했다.

| 시트 | label이 바뀐 행 | 변경률 |
|---|---|---|
| 전문가 A-1 | 9 / 30 | 30.0% |
| 전문가 A-2 | 4 / 30 | 13.3% |
| 검수자 B | 10 / 30 | 33.3% |

- 처리: "세 자동 규칙 시트는 모두 **무효로 폐기**하고 어떤 점수·유의성 검정에도 쓰지 않는다."
- 그 뒤 실제 의미 판독으로 82행(Q001~Q003)을 다시 표시했지만 전체 2,652행 중 일부이므로 최종 평가로 합치지 않았다.
- 최종 평가는 (1) 현재 RRF 상위 10만 전수 의미 판독하거나 (2) 후보 풀 2,652행을 전수 의미 판독한 뒤 검정을 적용하는 두 길 중 하나를 결과 전에 고정하고 별도 작업으로 하기로 했다(285~290줄).

## 4. PR 문서에 적혀 있지 않은 것

이 문서가 짐작으로 채우지 않은 부분이다.

- 재감사를 누가(사람인지 AI인지)·어떤 순서로 했는지는 15절에 적혀 있지 않다.
- 고정 해시가 어떤 해시 함수인지, 30행을 어떤 방식으로 골랐는지 적혀 있지 않다.
- A-1·A-2·B 시트가 각각 몇 행이었는지는 15절에서 확인되지 않는다(재감사 30행만 적혀 있다).
- "label 변경"이 3단계 라벨(0·1·2) 중 어느 쪽으로 바뀐 것인지(관대해졌는지 엄격해졌는지)는 적혀 있지 않다.

## 5. 읽는 법 — 이 문서에서 계산한 것과 해석

- **이 문서에서 계산**: 30행 표본이라 변경률 자체도 불확실하다. Wilson 95% 구간은 9/30이 16.7~47.9%, 4/30이 5.3~29.7%, 10/30이 19.2~51.2%다. 가장 낮은 값(4/30)의 구간 하한도 5%를 넘어서, 세 시트 모두 "거의 바뀌지 않는다"고 보기 어렵다.
- 해석(이 문서의 의견): 규칙으로 붙인 라벨은 속도를 얻는 대신 라벨이 질문마다 다시 읽을 때마다 달라질 수 있는 상태가 된다. 그래서 (1) 라벨은 사람이 두 글을 읽고 표시하고, (2) 표시 뒤 고정 표본을 다시 표시해 변경률로 신뢰를 확인하며, (3) 신뢰 점검을 통과하지 못한 라벨로는 점수를 내지 않는다.
- 이 저장소의 `AGENTS.md` 5-2는 평가 정답을 AI가 지어내지 않고 사람이 표시한다고 정한다. PR #133의 평가 흐름은 AI가 바꿔 쓴 예상 질문과 AI 심사자·규칙의 표시를 평가 근거로 삼았기에 그 규칙과 충돌 소지가 있어 **질문·라벨·점수는 가져오지 않았다.** 시점 평가의 AI 표시 예외는 DEC-079가 따로 다룬다.
