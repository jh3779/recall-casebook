## 회전 시 포인트 이탈 수정 (2026-10-13 후속)

## 추정 형상의 범위

`estimatedParts.ts`는 일반적인 전륜구동 차량의 부품 배치를 차체 크기에 맞춰 그린다. 원본에 연결된 부품 분류는 중복 생성하지 않는다. 엔진 블록·상부·벨트 풀리, 변속기 하우징, 전원 영역, 연료 배관, 조향 랙·컬럼, 서스펜션, 에어백, 제동등 스위치, 도어 래치를 단순화했다. 쏘나타 10개 분류와 쏘렌토 4개 분류에 3D 표시가 연결된다.

추정 도형은 `userData.estimated`로 원본과 구분하고 **외관에서는 숨긴다**. 투시에서도 현재 실제 리콜이 있는 분류만 표시한다. 선택한 분류가 있으면 다른 추정 도형은 숨긴다. 기타 장비처럼 위치를 한 곳으로 특정할 수 없는 분류는 원문만 연다. 추정 도형을 생성해도 리콜 원문·원인·번호·공급사를 만들거나 바꾸지 않는다.

화면 범례, 핫스팟, 부품 목록·상세에 **추정 위치·설명용 표시**를 명시한다. 부품 형상·위치는 제조사 도면이나 NHTSA가 확인한 실제 결함 위치가 아니다. 버튼은 '부품 투시'로 표시한다. 도형 추가 사실도 저작자 크레딧에 포함한다.

## 모델 처리

`frontend/src/showroom/vehicle.ts`에서 원본 법선·텍스처·스킨을 유지한다. 과거 유한요소 트럭용 면 정리·법선 재계산을 새 모델에 적용하지 않는다. 코나 23개 메시, 쏘렌토 원본 127개 메시가 부품 대응표에 들어간다. 코나의 선 요소 3개는 부품 선택 메시에서 제외한다.

두 파일은 원점·단위·앞 방향이 다르다. 전체를 그룹에 넣고 등방 축척으로 길이를 화면 5.2 단위에 맞춘 뒤 앞을 +x, 운전석 쪽을 -z로 정렬한다. 차체 중앙 x/z를 0, 바닥을 y=0으로 맞춘다. 두 차량의 실제 크기 비교 용도가 아니다. 회전 중심 `(0, 0.8, 0)`, 수평 회전 각도, 팬 제한은 앞선 회전축 수정 그대로다.

코나는 원본 텍스처를 유지하며 `CeramicBlue` 도장면만 색상 선택에 연결한다. 쏘렌토는 이미지 텍스처가 없고 재질이 같은 회색이어서, 명시된 재질 이름을 도장·유리·타이어·휠·등화·하부 재질로 연결한다. 본 이름과 메시 이름이 확인된 부품만 분류에 연결한다. 생성 과정은 `frontend/scripts/prepare-vehicle-parts.mjs`로 재현한다.

쏘렌토는 왼쪽 앞바퀴 `wheel_lfchild` 한 벌(타이어·휠 메시 2개)만 들어 있었다. 나머지 세 바퀴의 본은 있어 해당 지점으로 복제하고 오른쪽은 좌우 반전한다. 복제 후 렌더링 메시 133개다. 원본 바퀴 지점의 앞뒤 높이 차이는 그대로 유지한다. 차체나 내부 부품을 새로 모델링하지 않았다.

## 부품 표시와 리콜 범위

외관 모델에 엔진·브레이크와 같은 계통 형상이 있어도 리콜에 명시된 제어 모듈·파이프 자체를 뜻하지 않는다. 화면에 이 한계를 표시하고, 배터리·배선처럼 위치를 확인할 수 없는 분류도 원문 목록은 열 수 있게 했다. 두 차종 사이 같은 분류 전환도 유지한다.

코나는 네 브레이크가 한 메시라 전체 중심으로 표시하면 차체 가운데에 점이 놓였다. 메시의 실제 정점에서 운전석 쪽·앞쪽 범위를 골라 앞 브레이크 위치를 표시하도록 고쳤다. 쏘렌토 엔진 메시에는 떨어진 두 표면이 포함되며 운전석 쪽 표면의 중심을 표시한다. 외관을 해체하거나 결함 부품의 위치를 추측하지 않는다.

보관된 NHTSA `FLAT_RCL_POST_2010.zip`과 카드에서 차종·연식을 정확히 추려 새 데모 파일을 생성한다. 트럭의 리콜을 새 차종에 재사용하지 않는다.

| 차종 조건 | 연식 | 리콜 수 | 제외 범위 |
|---|---|---:|---|
| HYUNDAI / KONA ELECTRIC | 2019–2021 | 4 | 가솔린 KONA, 범위 밖 연식 |
| KIA / SORENTO | 2021–2023 | 8 | SORENTO HYBRID·PHEV, 범위 밖 연식 |

차량 리콜(`RCLTYPECD=V`)만 포함한다. 스냅샷 날짜는 2026-10-06이고 최신 목록이나 검색 결과가 아니다. 결함·위험·시정·회사명 4개 칸은 보관 카드와 바이트 대조해 12/12건 일치했다. 각 리콜의 NHTSA 원문 링크, 원본 파일 SHA-256, 정확한 차종·연식·원본 RECORD_ID를 보존한다. 한 리콜에 여러 분류가 있을 수 있어 분류별 합계는 차종의 리콜 수와 다를 수 있다. 검색 API·RAG 색인·평가셋은 수정하지 않았다.
