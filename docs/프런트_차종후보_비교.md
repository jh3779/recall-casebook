## 재현

저장소 루트에서 기존 flat 판독기를 사용한다. `make`, `model`, `first`, `last`를 위 표 값으로 바꾸면 같은 조건을 재집계할 수 있다.

```python
from pathlib import Path
from scripts.defect_precedent.nhtsa import RCL_COLS, read_flat

make, model, first, last = "HYUNDAI", "SONATA", 2011, 2014
rows = read_flat(Path("data/raw/nhtsa/FLAT_RCL_POST_2010.zip"), RCL_COLS)
campaigns = {
    r["CAMPNO"]
    for r in rows
    if r["RCLTYPECD"] == "V"
    and r["MAKETXT"] == make
    and r["MODELTXT"] == model
    and r["YEARTXT"].isdigit()
    and first <= int(r["YEARTXT"]) <= last
}
print(len(campaigns))  # 18
```

전체 후보 집계와 선택 범위 재집계의 수치를 대조했다. 최종 선택·구현·검사 결과는 `프런트_현대기아_모델.md`에 기록한다. 모델 구매는 하지 않았다.
